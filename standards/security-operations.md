# 安全、外部调用与运行规范

- **SEC-01 MUST** 认证、角色、对象范围和状态服务端验证，查询/详情/导出/附件/轮询一致；前端隐藏不是安全边界。可信网关头需证明来源，框架默认设置不能代替完整访问链分析。
- **SEC-02 MUST** 凭据、备份、真实客户数据不进入Git、截图、普通日志或发布包。使用受限外部配置和脱敏示例；审计记录操作者/动作/目标/结果，错误提供安全关联编号。
- **SEC-03 MUST** 外部URL限制协议/来源、重定向、大小与超时；用户/模型/检索文本都是数据，不得覆盖系统规则或触发隐式工具执行。
- **AI-01 MUST** 模型/外部系统通过明确适配器；角色、参数、发布版本可追踪。输出结构/事实/引用/权限校验后保存，不将生成建议冒充来源原文。
- **AI-02 MUST** 调用链记录次数、总deadline、并发与重试预算。虚拟线程不是容量控制；分别说明等待、HTTP超时、取消传播和未知结果。不得自动增加二次复核而不说明行为/成本。
- **JOB-01 MUST** 同步请求、内存活跃态和持久任务分开命名；“生成中”不代表已有队列。需要跨重启恢复时定义认领、失联、执行标识、幂等和过期写回保护。
- **OPS-01 MUST** 开发/测试/生产分别授权，发布关联确定源码、产物摘要、数据版本和环境。合并代码不等于部署，配置保存不等于业务发布。
- **OPS-02 MUST** 数据迁移与程序切换有备份、维护/排空、显式迁移、校验和回退门槛；程序回退与数据恢复分离，不覆盖新数据。普通测试不能被用作生产验收证据。
- **OPS-03 SHOULD** 定义日志访问/轮转/空间上限及备份保留与恢复目标；应用、数据库、外部服务分别诊断。指标需实测，不虚报p95/可用率或真实费用。
- **OPS-04 MUST** 批量删除/备份清理先确认归属、当前引用与保留集，使用明确清单并检查结果；没有授权不能扩展到其他用户/应用或自动清理任务。
