# v0.2检查补强与适配实施计划

目标：先修复三个已验证缺口，再补可执行技术适配与完整教学闭环；按用户授权完成回归、文档、提交推送。

## 范围和决策

- 项目/追踪契约升级schema 2，旧schema 1不能静默当ready或completed通过，保留历史验收并提供迁移说明。
- 命令执行先校验完整项目资料；超时先TERM宽限再KILL，隔离资源必须配置清理及残留检查，异常也执行，清理失败不通过。
- 生成结构化证据，关联实际命令、环境、时间、返回码、源码指纹和规格摘要；拒绝空证据、非通过记录、规格/源码漂移。证据不是签名，不能证明恶意篡改或业务正确。
- 新增Java/Spring、前端、PostgreSQL适配说明及可执行样例；适配包不自动安装框架或连接数据库。
- 完整示例使用可运行的合成离线工程和真实生成的演示证据；演示证据不用于目标业务验收。
